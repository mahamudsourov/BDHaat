
A full-stack "district-based e-commerce platform" for Bangladesh where customers can buy traditional famous products (e.g., Jamdani from Narayanganj, sweets from Tangail, handicrafts, etc.) and healthy local foods (e.g., Modhu, Honeynuts, Badam). 


The system supports two roles:

Customer

Admin

🛒 Customer Features:

🔑 User Registration & Login – Create account, login securely, manage profile.

🔍 Search & Filter – Search products by name, category, or district with filtering options (price, type).

📝 Product Details Page – View product description, images, price, stock status.

🛍️ Add to Cart – Add products to shopping cart for later checkout.

💳 Place Orders – Complete order via checkout process.

💰 Payment Options – Support for Cash on Delivery.

💬 Messaging/Support – Customers can send queries or messages to admin.


🛠️ Admin Features:

👥 Customer Management – View, approve, block, or delete customer accounts.

📦 Product Management – Add, update, delete products with categories (district-based, healthy foods).

🛍️ Order Management – Monitor all customer orders, confirm deliveries, and update order status.

💰 Payment Management – Verify and track customer payments.

📩 Message Management – Receive and respond to customer queries.

🖥️ Admin Dashboard – Full control panel to manage products, customers, orders, and payments.


🖥️ Frontend: Responsive interface built with HTML, CSS, JavaScript.

⚙️ Backend: Secure & scalable backend using PHP (Laravel Framework).

🗄️ Database: MySQL database for storing users, products, and orders.

🔐 Authentication & Authorization: Role-based access control (Admin/Customer).

📱 Responsive Design: Works on desktop, tablet, and mobile devices.
